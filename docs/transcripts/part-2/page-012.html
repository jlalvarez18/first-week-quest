# Claude Code Transcripts: Installation & Usage

## Installation

Install via `uv`:
```
uv tool install claude-code-transcripts
```

Or run without installing:
```
uvx claude-code-transcripts --help
```

## Converting a Local JSONL File to HTML

```
claude-code-transcripts json session.jsonl --open
```

Or specify an output directory:
```
claude-code-transcripts json session.jsonl -o output-directory/
```

## Selecting a Session (Interactive)

**Local sessions** (stored in `~/.claude/projects`):
```
claude-code-transcripts
```
Or explicitly:
```
claude-code-transcripts local
```

**Web sessions** (via Claude API):
```
claude-code-transcripts web
```

Control how many sessions display:
```
claude-code-transcripts local --limit 20
```

## Output Locations

- **Default behavior**: Generates HTML in a temporary directory and opens it in your default browser
- **With `-o` flag**: Writes to your specified directory
- **With `-a` flag**: Creates auto-named subdirectory based on session ID
- **Generated files**: `index.html` plus paginated `page-001.html`, `page-002.html`, etc.

## Key Output Options

```
-o, --output DIRECTORY          # Specify output directory
-a, --output-auto              # Auto-name subdirectory by session ID
--open                         # Open in browser
--gist                         # Upload to GitHub Gist
--json                         # Include original session file
```
